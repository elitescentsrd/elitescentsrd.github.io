# Skills de diseño de Emil Kowalski

Copiadas de [emilkowalski/skill](https://github.com/emilkowalski/skill) (commit `e8a175d`, 2 de octubre de 2026), con licencia MIT (ver `LICENSE-emilkowalski`). Claude Code las carga solas en este proyecto, para que la tienda y el panel sigan las mismas reglas de movimiento y diseño:

- `emil-design-eng`: la filosofía y las reglas principales (curvas, duraciones, presionar, hover, accesibilidad).
- `animate` (con `RECIPES.md`): cómo construir cada animación.
- `review-animations` (con `STANDARDS.md`): revisión estricta de animaciones.
- `find-animation-opportunities`: dónde sí conviene animar y dónde no.
- `mobile-native`: detalles para que se sienta como app en el celular (toques, campos, muesca).
