# Elite Scents RD

Sitio oficial de Elite Scents RD.

## Estructura
- `index.html`: página principal
- `catalogo.html`: visor del catálogo página por página
- `pages/`: 36 páginas optimizadas del catálogo
- `pedidos-envios.html`: información de pedidos y entregas
- `privacidad.html`: aviso de privacidad
- `social-card.png`: vista previa al compartir
- `sitemap.xml` y `robots.txt`: descubrimiento para buscadores
- `404.html`: página de error personalizada

El sitio está optimizado para móvil y computadora y mantiene un único acceso visible a WhatsApp.
